谁负责创建？

Node 通常由 kubelet 注册；DRA driver 把发现的设备写进 ResourceSlice；管理员准备 DeviceClass。用户提交 Claim 和 Pod，由调度器决定具体分给哪张卡。

三个名字，别看串了

Pod 里的 gpu 是本地别名，train-gpu 是 Claim 对象名，accelerator 是 Claim 里的请求名。先沿着 resourceClaimName 找 Claim，再沿着 deviceClassName 找 Class。

分配完，卡去哪了？

假设分到 gpu-0，它仍然留在 Slice 的设备列表里。Claim status 记录实际分配的 driver、pool、device。Slice 是库存，不能因为列表里还有这张卡，就判断它空闲。

用户怎么找 Class？

先运行 kubectl get deviceclasses，再用 kubectl get deviceclass gpu-any -o yaml 看规则。需要相应读取权限；通常平台也会提供可申请的 Class 清单。DeviceClass 没有 namespace，Claim 和 Pod 则必须在同一个 namespace。
